STRATEGY 01 Baseline

Simple Chunking

RecursiveCharacterTextSplitter

Splits text into fixed size chunks (500 chars) with a sliding window overlap (50 chars). It searches ChromaDB using cosine distance. 

text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=500,
    chunk_overlap=50
)
chunks = text_splitter.split_documents(docs)
retriever = vectorstore.as_retriever(k=3)

STRATEGY 02 Smart Splitting

Semantic Chunking

SemanticChunker

Evaluates consecutive sentences using embedding distances. Splits text only where a topic shift or contextual break occurs. 

text_splitter = SemanticChunker(
    embeddings=self.embeddings
)
chunks = text_splitter.split_documents(docs)
retriever = vectorstore.as_retriever(k=3)

STRATEGY 03 Recommended

Hybrid Search

EnsembleRetriever (Chroma + BM25)

Combines dense vector search (meaning/concepts) with sparse BM25 (exact keyword match) using 50/50 reciprocal rank fusion. 

ensemble = EnsembleRetriever(
    retrievers=[vector_retriever, bm25_retriever],
    weights=[0.5, 0.5]
)
return ensemble

STRATEGY 04 Highest Accuracy

Cross-Encoder Re-ranking

ContextualCompressionRetriever

Fetches a broad top-10 candidate pool from Chroma, then uses a HuggingFace cross-encoder model to re-score and keep the top 2. 

model = HuggingFaceCrossEncoder("cross-encoder/ms-marco-MiniLM-L-6-v2")
compressor = CrossEncoderReranker(model=model, top_n=2)
return ContextualCompressionRetriever(
    base_compressor=compressor, base_retriever=top_10
)
